# GitHub-to-Zenodo release checklist

1. Create the public repository `Weyl-Center-for-Mathematical-Physics/rk-choi-complete-positivity`.
2. Upload the repository contents to the default branch.
3. Confirm that `LICENSE`, `CITATION.cff`, and `.zenodo.json` are present at the repository root.
4. In Zenodo, link the GitHub account that has access to the organization.
5. In Zenodo's GitHub integration, synchronize repositories and enable `rk-choi-complete-positivity`.
6. Create a GitHub release tagged `v1.0.0` using the release title `rk-choi-complete-positivity v1.0.0`.
7. Wait for Zenodo to archive the release and issue the version-specific DOI.
8. Verify the creator order, ORCIDs, MIT license, title, description, and files on the Zenodo record.
9. Insert the version-specific DOI into the article's Data availability statement and the journal submission metadata.
10. Use the Zenodo concept DOI for future-version citation only when a version-independent identifier is desired.
